# HellovNeet — Vineet Sharma Portfolio

Personal portfolio for Vineet Sharma, a B.Voc Internet of Things student building projects with Arduino, ESP32, sensors, web technologies and interactive interfaces.

## Tech

- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion / Motion
- Lucide React
- Recharts

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

The production output is generated in `dist/`.

## Vercel

This is a standard Vite SPA. Vercel can deploy it directly from the repository:

- Framework preset: **Vite**
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

No API key or server runtime is required for the portfolio.
